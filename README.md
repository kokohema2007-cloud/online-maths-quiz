## 🌟 نظرة عامة على المشروع (Project Overview)
منصة ويب تفاعلية فائقة السرعة وعصرية مبنية بكود قياسي خالص (**Vanilla HTML5, CSS3, Modern JavaScript ES6+**) وبدون أي أطر عمل ثقيلة (Zero External Frameworks). تم تصميم المنصة خصيصاً لمراجعة وامتحانات مادة **GEN002 Mathematics 1** لطلاب الهندسة وفقاً لأحدث المناهج الجامعية وأوراق الامتحانات الحقيقية للميدتيرم والمذكرات الأكاديمية المعتمدة.

تعمل المنصة فورياً ومجاناً على **GitHub Pages**، كما أنها متوافقة كلياً كـ **Progressive Web App (PWA)** لتعمل كتطبيق هاتف ذكي أوفلاين مع تخزين محلي كامل ومؤثرات صوتية اصطناعية عبر **Web Audio API**.

## 🛠️ المعمارية التقنية ومميزات النظام (Core Features)

### 1. بنك الأسئلة المعياري وأنماط التقييم التفاعلي (69 سؤالاً جامعياً):
- **أسئلة صح أو خطأ (True / False):** 20 سؤالاً تفاعلياً مع شروحات دقيقة للنظريات والاستثناءات (مثل دوال المقياس $f(x)=|x|$، المماس الرأسي، وتقليص المجالات).
- **أسئلة اختيار من متعدد (MCQ):** 17 سؤالاً شاملاً مع تنسيق معادلات لاتيك (**KaTeX**) عالي الدقة.
- **أسئلة إدخال وحساب نواتج (Calculation Inputs):** 10 مسائل لحساب المشتقات والميول ومعدلات التغير مع فحص هامش الخطأ الرقمي ($\pm 0.001$).
- **محرك تصحيح الأخطاء التفاعلي (Interactive Fix Engine):** 6 مسائل تفاضل مقسمة لخطوات متسلسلة بها خطأ خفي شائع (مثل إشارات الدوال الزائدية، نسيان قاعدة السلسلة، أو تربيع المعاملات)، يكتشف الطالب الخطوة الخاطئة بضغطة زر.
- **الأسئلة المقالية والإثباتات (Essay & Proofs):** 6 إثباتات رياضية كبرى مع زر ذكي لكشف خطوات الحل والإثبات الأكاديمي المعتمد بالتفصيل.
- **نظام قفل الإجابات الإجباري (Mandatory Answer Locking):** بمجرد نقر أو إرسال الإجابة، تُقفل الحقول فورياً ويظهر التقييم مع كشف الشرح ومنع التخمين العشوائي.
- **لوحة متابعة النتائج اللحظية:** شريط التقدم، النسبة المئوية للإتقان، وسلسلة الإجابات الصحيحة المتتالية (**Streak 🔥**).
- **فلتر مراجعة الأخطاء فقط (Mistakes Only):** زر ذكي لعزل المسائل التي أخطأ فيها الطالب لإعادة التدرب عليها حتى الإتقان.

### 2. وضع التحدي والدمار (Extreme Mode - Final Boss Level 🔥💀🔥):
- تبويب مخصص لأعقد مسائل الامتحانات الجامعية:
  1. مسائل امتحان الميدتيرم الحقيقي للدكتورة أماني محمد (السؤال الأول: تفاضل الكسر المركب العملاق، الدالة بأس متغير، تفاضل اللوغاريتم، و $\mathrm{csch}^{-1}$).
  2. المشتقات الجزئية العليا من الرتبة الثالثة $f_{yxy}$ للدالة $f(x,y) = x e^{xy}$.
  3. جدول الصواب المنطقي لمسألة الميدتيرم: $(( \bar{p} \leftrightarrow q) \oplus (p \wedge \bar{q})) \rightarrow \bar{q}$.
  4. تركيب الدوال $f \circ g$ و $g \circ f$ وتحديد المجالات الرياضية بدقة.
  5. إثباتات المذكرة اليدوية: إثبات المعادلة التفاضلية $x^2 y'' + 7xy' + 5y = 0$ لمنحنى $y = \frac{\cosh(2\ln x)}{x^3}$.
  6. إثبات الكتاب الجامعي الشهير: $x^4 + y^4 = 16 \implies y'' = -48 \frac{x^2}{y^7}$.
- **خلفية سينمائية حارقة:** جسيمات لهب ديناميكية متطايرة عبر **HTML5 Canvas**.
- **مؤثر صوتي جهوري ملحمي (Sub-bass cinematic boom)** عبر Web Audio API.

---

### 3. محرك تشخيص نقاط الضعف بالذكاء الاصطناعي (AI Tutor):
- يحلل دقة الطالب ونسبة إنجازه في **7 موضوعات أساسية للمادة**:
  1. قواعد التفاضل وقاعدة السلسلة وميول المماسات.
  2. الدوال المثلثية وعكوسها (Trig & Inverse Trig).
  3. الدوال الزائدية وعكوسها (Hyperbolic Functions).
  4. الاشتقاق الضمني واللوغاريتمي والمشتقات العليا.
  5. النهايات وقاعدة لوبيتال والصيغ غير المعينة.
  6. المشتقات الجزئية ودوال المتغيرات المتعددة والدوال التوافقية (Laplace & Wave).
  7. المنطق الرياضي وجداول الصواب والمجموعات والدوال المركبة.
- يكتشف الموضوعات التي تقل نسبة إتقانها عن 50% ويطلق تحذيراً تربوياً تشخيصياً.
- يقترح كروت دروس يوتيوب منتقاة بعناية بروابط مباشرة لمشاهدة الشروحات وعلاج القصور.

---

### 4. المختبر الرياضي والمحاكي التفاعلي المدمج (Calculus Studio):
- **حاسبة المشتقات خطوة بخطوة (Derivative Step-by-Step Solver):** تعرض صيغة الدالة، القاعدة المطبقة، الخطوات الجبرية، والناتج النهائي.
- **حاسبة خط المماس والعمودي (Tangent & Normal Line Calculator):** تحسب نقطة التماس وميل المماس $m = f'(x_0)$ ومعادلتي خط المماس والخط العمودي بصيغة الميل ونقطة.
- **مستنتج الدوال الزائدية التبادلي (Hyperbolic Evaluator):** إدخال قيمة $\sinh x$ واستنتاج الدوال الخمس الأخرى فورياً ($\cosh, \tanh, \coth, \mathrm{sech}, \mathrm{csch}$) مع التحقق من متطابقة فيثاغورس الزائدية $\cosh^2 x - \sinh^2 x = 1$ (Example 19 & Ex. Z).
- **محاكي ومولد جداول الصواب المنطقية (Truth Table Generator):** يولد جدول الصواب خطوة بخطوة لمسألة الميدتيرم وقوانين دي مورجان ويصنف العبارة (Contingency / Tautology).

## 🚀 كيفية تشغيل المنصة ونشرها على GitHub Pages

### التشغيل المحلي الفوري (Local Testing):
يمكنك تشغيل المنصة فورياً بفتح ملف `index.html` في أي متصفح، أو عبر أي سيرفر محلي مثل:
```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```
ثم فتح الرابط: `http://localhost:8080`

### النشر المجاني على GitHub Pages (Deploy in 1 Minute):
1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً باسم: `gen002-math1-platform`).
2. ارفع كافة الملفات الموجودة في هذا المجلد إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "Initial release of GEN002 Mathematics 1 Exam Platform"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/gen002-math1-platform.git
   git push -u origin main
   ```
3. ادخل إلى إعدادات المستودع (**Settings**) -> ثم تبويب **Pages**.
4. اختر الفرع `main` والمجلد `/ (root)` واضغط **Save**.
5. خلال ثوانٍ، ستكون منصتك متاحة عالمياً على الرابط:  
   `https://YOUR_USERNAME.github.io/gen002-math1-platform/`
